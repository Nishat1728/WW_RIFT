# Code of conduct

We are committed to a respectful, harassment-free collaboration environment. Be constructive,
assume good faith, document scientific disagreements with evidence, and respect data licences and
privacy. Harassment, discriminatory language, personal attacks, and publication of another
person's private information are not acceptable.

Repository maintainers may edit or remove contributions and restrict participation when conduct
is harmful to the project or its community. Report conduct concerns privately to the repository
owner through their GitHub profile.
