# Security policy

## Supported version

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue containing credentials, private service URLs, or exploitable details.
Use GitHub's private vulnerability-reporting feature for this repository. If that feature is not
available, contact the repository owner privately through their GitHub profile.

Never include `.netrc`, `.cdsapirc`, API tokens, provider cookies, or downloaded restricted data in
a report. Replace all secrets with descriptive placeholders.
